## 已完成功能

### ✅ P0-1：客户购买时间字段

**修改文件**：
- `backend/database.py` - 新增字段和计算函数
- `backend/main.py` - API 接口更新
- `frontend/index.html` - 购买历史组件

**核心功能**：
1. 购买历史 JSON 数组存储
2. 固定价格体系（4/6/8/10疗程）
3. 自动计算粒数和金额
4. 侧边栏显示最新购买信息
5. 下拉展示购买历史 + 新增/删除功能

**数据结构**：
```json
{
  "date": "2024-08-01",
  "cycles": 6,
  "pills": 180,
  "amount": 3960
}
```

**固定价格**：
| 疗程 | 粒数 | 价格 |
|------|------|------|
| 4疗程 | 120粒 | 2970元 |
| 6疗程 | 180粒 | 3960元 |
| 8疗程 | 240粒 | 4950元 |
| 10疗程 | 300粒 | 5940元 |
