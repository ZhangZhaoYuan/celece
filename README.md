# 小赛助手 🏆

赛乐赛瘦身顾问销售助手 — 基于 FastAPI + sqlite-vec 的 CRM 系统

## 功能概览

| 功能 | 说明 |
|------|------|
| **客户管理** | 客户信息管理、分组（CID/疗程/套餐）、购买历史记录 |
| **话术生成** | AI 自动生成瘦身顾问话术，支持多模型轮询 |
| **知识库** | 文档上传管理、自动向量化、生成话术时自动搜索 |
| **有效话术** | 自动收集有效话术、三级评分系统、AI 生成时参考 |
| **常见问题** | FAQ 管理、自动同步到知识库 |
| **图片索引** | 排油图/饮食图分类管理、语义搜索 |
| **跟进提醒** | 自动检测待跟进客户 |
| **有效话术评分** | 三级评分（即时反应+话术质量），按评分排序参考 |

## 技术栈

- **后端**: Python 3.11 + FastAPI + uvicorn
- **数据库**: SQLite + sqlite-vec（向量检索）
- **前端**: 单文件 HTML（内联 CSS/JS）
- **AI 模型**: 阿里云百炼 / 通义千问 / DeepSeek 等

## 快速开始

```bash

# 或
cd D:\小赛助手
python launcher.py
```

访问 http://localhost:8800

## 有效话术评分系统

生成话术时自动分析上一条话术效果：

| 评分维度 | 分值 |
|---------|------|
| 成交信号（买/付款/下单） | +3 |
| 积极信号（好的/瘦了/谢谢） | +2 |
| 中性回应（有回复） | +1 |
| 消极信号（拒绝/反驳） | -1 |
| 话术质量（提问/数据/情感） | +1~+3 |

评分 ≥ 2 自动存入有效话术库，下次生成时优先参考。

## 客户备注

每个客户自动生成性格分析备注，包含：
- 性格特点、沟通风格
- 关注点、有效策略
- 注意事项

AI 生成话术时自动参考客户备注。
